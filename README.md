# customer-marketing-analytics
Customer marketing analytics project using Excel, SQL, Python and Power BI.
## Project Overview

This project analyzes customer behavior, spending patterns and marketing campaign performance using Excel, SQL, Python and Power BI.

## Analysis

- Customer segmentation
- Income and spending analysis
- Product category analysis
- Purchase channel analysis
- Campaign performance
- Customer demographics

## Tools

- Excel – Data exploration and analysis
- SQL – Data analysis and segmentation
- Python – Data analysis and visualization
- Power BI – Interactive dashboard

## Dashboard

The Power BI dashboard includes two pages:

- Customer Marketing Analytics
- Customer & Campaign Insights
